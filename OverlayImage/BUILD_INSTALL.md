# OverlayImage Build & Installation Guide\n\n## Prerequisites\n\nYou must have a jailbreak development environment set up with:\n\n1. **Theos** — Build system for iOS tweaks\n2. **Logos** — Logos preprocessor (part of Theos)\n3. **LLVM/Clang** — C/Objective-C compiler (included in Xcode or Theos)\n4. **iOS 18 SDK** — Or compatible SDK for your target iOS version\n5. **A jailbroken iOS device** — Or simulator for testing\n\n### Setup Steps (macOS)\n\nIf you don't have Theos installed:\n\n```bash\ncd ~\ngit clone --recursive https://github.com/theos/theos.git\nexport THEOS=~/theos\nexport PATH=$THEOS/bin:$PATH\n```\n\nVerify installation:\n\n```bash\ntheos --version\n```\n\n---\n\n## Build Instructions\n\n### 1. Navigate to Project Directory\n\n```bash\ncd /path/to/OverToolIOS/OverlayImage\n```\n\n### 2. Set Environment Variables (if not already set)\n\n```bash\nexport THEOS=~/theos  # Adjust path if needed\nexport PATH=$THEOS/bin:$PATH\n```\n\n### 3. Clean (Optional)\n\n```bash\nmake clean\n```\n\n### 4. Build the Tweak\n\n```bash\nmake\n```\n\n**Expected Output:**\n```\n making all for tweak OverlayImage…\nClangCompile Tweak.xm\n Clang Compile OverlayManager.m\n Clang Compile OverlayWindow.m\n Clang Compile OverlayView.m\n Clang Compile ImagePickerController.m\nClangLink OverlayImage\n…/OverlayImage/.theos/obj/debug/OverlayImage.dylib (successful)\n```\n\n### 5. Build and Package (.deb)\n\nTo create a `.deb` package (Debian package for Cydia/Sileo):\n\n```bash\nmake package\n```\n\n**Output:**\n```\nDEBName: OverlayImage_1.0_iphoneos-arm64.deb\n```\n\n### Troubleshooting Build Errors\n\n| Error | Cause | Solution |\n|-------|-------|----------|\n| `theos: command not found` | Theos not in PATH | Set `export THEOS=~/theos` and add to `$PATH` |\n| `SDKVersion not found` | iOS SDK missing | Run `$THEOS/bin/nic.pl` to configure SDK path |\n| `frameworks not found (UIKit, QuartzCore)` | Framework search paths incorrect | Update `Makefile`: ensure `FRAMEWORK_SEARCH_PATHS` includes SDK frameworks |\n| `Undefined symbols for architecture arm64e` | Missing linker flags | Verify `Makefile` includes `-fobjc-arc` and framework names |\n\n---\n\n## Installation Instructions\n\n### Option A: Via USB / File Transfer (Recommended for Development)\n\n#### 1. Build the .deb\n\n```bash\nmake clean\nmake package\n```\n\nThe `.deb` file is located at:\n```\n./packages/OverlayImage_1.0_iphoneos-arm64.deb\n```\n\n#### 2. Transfer to Device\n\nUsing **iDevice Manager**, **USB interface**, or **SSH**:\n\n**Via SSH (if device is on same network):**\n```bash\nscp ./packages/OverlayImage_1.0_iphoneos-arm64.deb root@<DEVICE_IP>:/tmp/\n```\n\n**Via USB (using tools like `ifuse` or `iproxy`):**\n```bash\niproxy 2222 22 &\nscp -P 2222 ./packages/OverlayImage_1.0_iphoneos-arm64.deb root@localhost:/tmp/\n```\n\n#### 3. Install on Device\n\nSSH into the device:\n```bash\nssh root@<DEVICE_IP>\n```\n\nOr via proxy:\n```bash\nssh -p 2222 root@localhost\n```\n\nInstall the .deb:\n```bash\ndpkg -i /tmp/OverlayImage_1.0_iphoneos-arm64.deb\n```\n\nReboot SpringBoard:\n```bash\nkillall SpringBoard\n```\n\n### Option B: Via Package Manager (Cydia / Sileo / Zebra)\n\n#### 1. Add Repository\n\nIf you're hosting the .deb on a repo:\n\n1. In **Cydia / Sileo**, add repo: `https://your-repo-domain.com`\n2. Search for \"OverlayImage\"\n3. Tap \"Install\"\n\n#### 2. Verify Installation\n\nAfter respring/reboot, check if tweak is loaded:\n```bash\ngrep -i overlayimage /var/log/system.log\n```\n\n---\n\n## Verification After Installation\n\n### 1. Check Dylib Loaded\n\n```bash\nls -la /Library/MobileSubstrate/DynamicLibraries/OverlayImage.dylib\n```\n\nShould return:\n```\n-rw-r--r-- 1 root admin 123456 <date> /Library/MobileSubstrate/DynamicLibraries/OverlayImage.dylib\n```\n\n### 2. Check Plist\n\n```bash\nls -la /Library/MobileSubstrate/DynamicLibraries/OverlayImage.plist\n```\n\n### 3. Verify Preferences Loaded\n\n```bash\ngrep -r OverlayImage /var/mobile/Library/Preferences/\n```\n\n### 4. System Log Check\n\nTo see debug output:\n```bash\nlog stream --predicate 'eventMessage contains[cd] \"Overlay\"' --level debug\n```\n\n---\n\n## Uninstallation\n\nTo remove the tweak:\n\n```bash\ndpkg -r OverlayImage\nkillall SpringBoard\n```\n\nOr use **Cydia / Sileo** → \"Installed\" → Swipe left → \"Remove\".\n\n---\n\n## Development Build & Test Loop\n\nFor faster iteration during development:\n\n### 1. Live Log Viewing\n\nIn a separate terminal, stream logs:\n```bash\nlog stream --predicate 'process == \"SpringBoard\"' --level debug\n```\n\n---\n\n## Makefile Reference\n\n### Current Makefile Structure\n\n```makefile\nTWEAK_NAME = OverlayImage\n\nOverlayImage_FILES = Tweak.xm OverlayManager.m OverlayWindow.m ImagePickerController.m OverlayView.m\nOverlayImage_FRAMEWORKS = UIKit QuartzCore Photos\nOverlayImage_CFLAGS = -fobjc-arc\n\ninclude $(THEOS)/makefiles/common.mk\ninclude $(THEOS_MAKE_PATH)/tweak.mk\n```\n\n### Optional Makefile Enhancements\n\n**Add warning flags:**\n```makefile\nOverlayImage_CFLAGS = -fobjc-arc -Wall -Wextra -Werror\n```\n\n**Add optimization:**\n```makefile\nOverlayImage_CFLAGS = -fobjc-arc -O2\n```\n\n**Add framework search path:**\n```makefile\nOverlayImage_FRAMEWORK_SEARCH_PATHS = $(THEOS)/vendor/iphonedev/Frameworks\n```\n\n---\n\n## Xcrun / Code Signing (Advanced)\n\nIf you need manual code signing:\n\n```bash\nxcrun --sdk iphoneos clang -fobjc-arc -framework UIKit -framework QuartzCore -framework Photos \\\n  Tweak.xm OverlayManager.m OverlayWindow.m OverlayView.m ImagePickerController.m \\\n  -o OverlayImage.dylib\n\n# Sign with entitlements (if jailbreak requires)\nldid -S OverlayImage.dylib\n```\n\n---\n\n## CI/CD Integration (Optional)\n\nFor automated builds, consider GitHub Actions or GitLab CI:\n\n### GitHub Actions Example\n\nCreate `.github/workflows/build.yml`:\n\n```yaml\nname: Build OverlayImage\n\non: [push, pull_request]\n\njobs:\n  build:\n    runs-on: macos-latest\n    steps:\n      -
